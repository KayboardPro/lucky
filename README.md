# 開運金爐 Deluxe

## 上線方式（GitHub Pages）
1. 到 GitHub 建立 Public repository，例如 `lucky-golden-furnace-deluxe`。
2. 將 ZIP 解壓縮，把 `index.html` 和 `mazu.png` 一起上傳到 repository 根目錄。
3. 進入 Settings → Pages。
4. Source 選 Deploy from a branch；Branch 選 `main`、資料夾選 `/(root)`，按 Save。
5. 等待部署完成，GitHub Pages 會顯示網站網址。

## 互動功能
- 點擊「丟入紙錢」逐張投入，最多 100 張。
- 每張紙錢有飛入動畫、金色粒子與紙張摩擦音效。
- 第 100 張投入後，媽祖圖像淡入、停留後淡出，並播放合成鐘聲與和聲。
- 音效可關閉，重新祈願可重置計數與動畫。
- 手機／平板響應式排版。

請注意：`mazu.png` 必須與 `index.html` 放在同一層。音效由瀏覽器即時合成，不需要額外音檔。若改用真實鐘聲或音樂，請使用取得授權的素材。此版本為原創重製原型，非參考網站原始碼。
